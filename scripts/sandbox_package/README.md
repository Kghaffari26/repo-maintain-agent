# ledgerlite

A tiny personal-finance helper: parse amounts from bank CSV exports, bucket
transactions by month, and print a monthly summary.

```bash
python -m pytest
```

This repository is the sandbox for the repo-maint agent
(https://github.com/Kghaffari26/repo-maintain-agent): its issues are triaged
automatically, and a "fix proposer" may open **draft** pull requests that a
human must review. Nothing is ever merged automatically.
